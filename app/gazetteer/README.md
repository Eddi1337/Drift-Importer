# Offline place names

`places.json` is a compact extract of GeoNames `cities15000.txt`, downloaded on
21 October 2026 from https://download.geonames.org/export/dump/cities15000.zip.
Each row is `[name, latitude, longitude, population, country_code]`.
Source zip SHA-256: 94fc1384d9ec03160b70b24c8d74c38421c541576ec4e26959490efcf1b6afd7.

Only public settlement coordinates are bundled. Private GPS is never sent to a
geocoding service. Labels describe a nearby town or city, not a precise address.
